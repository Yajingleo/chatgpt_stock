### What
This is a collection of python library and binary for stock selections.

### Why
Selection of stock is the first step of alpha-based strategies. We could build single-stock
or multi-stock portfolios, that have over-market alpha.

### How
1. Run each file: `python <file.py>`
2. Each file with give stocks recommendations and related finanial news / data.
3. Select the stocks that you would be trading.
